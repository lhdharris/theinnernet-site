Opening the beta

The Windows build isn't signed yet, so Windows will check with you the first time you open Innernet. After that, it opens like any other app.

macOS

  1. Open the download (Safari may already have unzipped it) and drag Innernet into your Applications folder.
  2. Double-click Innernet to open it. (It's signed and checked by Apple, so it opens straight away.)

Windows

  1. Right-click the download and choose Extract All. Innernet needs the files beside it, so run it from the extracted folder, not from inside the zip.
  2. Double-click Innernet.exe. If Windows says it protected your PC, click More info, then Run anyway.
  3. If Windows instead says Smart App Control blocked it, there's no way past that for an unsigned app. Please wait for the next beta, which will be signed. We don't suggest turning Smart App Control off.

Linux

  1. The AppImage runs anywhere: make it executable (in your file manager's Properties, allow it to run as a program, or chmod +x Innernet-x86_64.AppImage), then double-click it.
  2. Or install the package for your system, which puts Innernet in your app menu. In the folder you downloaded it to:
    • Debian, Ubuntu, Mint: sudo apt install ./Innernet-amd64.deb
    • Fedora: sudo dnf install ./Innernet-x86_64.rpm
    • openSUSE: sudo zypper install ./Innernet-x86_64.rpm
